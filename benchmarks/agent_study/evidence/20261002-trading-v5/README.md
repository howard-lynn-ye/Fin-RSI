# Earlier bundled-access development study (v5)

This is a separate frozen study, not another cell of the later factorial experiment.
The original 528 decision receipts and aggregate/report hashes were reverified before
publication. All model/seed results, non-submissions and failed calls are retained.
The library arm combines tools, documentation and adjusted-data adapters; its raw arm
has a different input interface. Do not pool these results with the four-condition study
or identify the contribution of an individual component from the bundle contrast.

The 7B seed-37 Slurm process ran out of memory after all 88 decisions and the inference
receipt were complete. The subsequent CPU scoring recovery verified that existing complete
receipt; it did not rerun model inference. See SCORING_RECOVERY_20261003.txt. This remains
a scheduler failure even though its complete decisions can be scored.

The posthoc directory reports additional risk, exposure, turnover, calls and exact adoption
from the same saved decisions. These diagnostics are post hoc and do not identify causal
mechanisms. Source/data/decision identity is recorded in the protocols and receipt maps.
Raw prices, model weights and original model outputs are retained on Beacon.
