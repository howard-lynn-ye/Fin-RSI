# Direct RAG access (v9)

This opt-in interface exposes `research_context(query)` directly in the library arm's prompt,
JSON actions and Python bindings. Its corpus contains installed skill/reference knowledge and
the same confined evidence snapshot available to both arms. It returns citations, exact study
signatures and package tool contracts. The model still chooses its research and investments.

Use `--interface v9` when freezing a new run. The version is `multisource-model-v4-rag`;
the default remains v8. The [v8 terminal objective and accounting](TERMINAL_RETURN_V8.md),
initial USD 100,000, deadline, costs, raw inputs and seven-plus-one response budget remain
unchanged. Report `100 * (ending_capital / initial_capital - 1)` and the paired difference in
percentage points. RAG does not supply a portfolio or guarantee a higher Return Rate.

Installed references describe the current library. Historical evidence retains its explicit
retrospective eligibility assumptions; it is not a verified archival vintage. Live collector
databases and network tools remain unavailable inside the replay. This change does not expand
the underlying news, sentiment, positioning or disclosure coverage.

The direct tool keeps bounded whole passages. If an entire package schema does not fit the
response budget, its name and `describe_library_tool` lookup remain explicit. Remaining large
responses use JSON text pages with offsets, rather than silent truncation. Small responses
return structured knowledge and evidence in one call. Study shortcuts and package tools use
different contracts; the response labels their respective calling routes.

Qualification exercises both JSON and bound Python retrieval in the actual confined worker,
rejects those tools in the raw arm, and retains the existing decision and capability gates.
The RAG qualification receipt is bound to the protocol, decision gate and inference receipt.
Model pilots must pass technical qualification before expanding a batch; retain failed model
decisions and all original frozen runs. Interface checks alone are not model-quality or return
measurements, and no new Return Rate is reported by this change.
