\section{Out-of-sample trading with and without the library}
\label{sec:trading}
Does an agent that can use \textsc{fin-skills} earn more than the same agent without it?
We froze a paired study before inference on real daily data for twelve US-listed
instruments: eight ETFs spanning equities, bonds, gold, and commodities, and four stocks
with splits during the history (two inside the test window). The agent sees a vendor-style
feed of unadjusted quotes and a dated table of splits and cash dividends; the hidden ledger
prices positions with total-return closes. Every ten sessions from
\TRWindowStart{} to \TRWindowEnd{} (\TRDecisions{} decisions), the agent inspects the data
available at that close, may call tools for up to eight turns, and submits long-only
weights that execute at the next close with 5 basis points per side. A failed decision
leaves holdings unchanged. Qwen2.5-Coder 7B, 14B, and 32B, released before the test window,
each run three sampling seeds per arm.

Both arms can read the files and run sandboxed NumPy, pandas, and SciPy code. The library
arm can also import \textsc{fin-skills} and call its catalog: the library builds split- and
dividend-adjusted inputs, runs one of 21 allocation, signal, risk, or forecasting methods,
and returns weights or lagged signals; guards and dated skill documents are available on
request. Prompts, budgets, and sampling are otherwise identical. The primary endpoint is
each path's net Sharpe ratio and cumulative return, paired by model and seed, with a
bootstrap over holding periods. Before any return was computed we replaced a tool format
that forced code into JSON strings, which made the 7B model fail every turn in the arm that
must write code; the change applies to both arms and is recorded with the aborted records.
