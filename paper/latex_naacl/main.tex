\begin{abstract}
Language models can invoke external quantitative libraries, yet raw tool access and unconstrained
verbal self-reflection (\texttt{Reflexion}) fail to produce sound financial research decisions when
domain conventions are fragmented, execution outputs contain look-ahead leaks, or iterative prompt
mutations overfit non-stationary regimes via reward hacking. We present \textsc{fin-skills}, an
open ecosystem of 129 source-verified financial skills, 48 algorithm backends, and 37 executable
verification guards integrated within a closed-loop agent architecture that couples two-stage
point-in-time progressive skill routing (\texttt{RAG-Jev}), a 64-Kenyon-Cell mushroom-body
associative memory module, and \textbf{Governed Financial Recursive Self-Improvement (\texttt{Fin-RSI})}.
Across $M=5$ seeds on \textsc{FinGuardBench-60} and a \PanelBalancedRows{}-row two-dimensional
company$\times$year balanced panel ($2018\text{--}2026$, distilled from \CorpusTotalShort{}
cross-market records across \CorpusAnnounceTickers{} A-share and \CorpusStockTwitsTickers{} US
tickers), progressive routing compresses prompt context by $98.9\%$ ($4{,}039 \pm 42$ tokens) with
$0.0\%$ schema fragmentation and zero future leaks, while counterfactual guard feedback lifts
verified repair pass rates from $17.5\% \pm 1.8\%$ to $96.2\% \pm 1.1\%$. Coupling verified
episode returns with gated mushroom-body plasticity improves annualized Sharpe from
$-0.58 \pm 0.11$ to $+1.71 \pm 0.14$ across 21 regimes, while evolving multimodal feature and
covariance operators inside our SHA-256-locked \texttt{Fin-RSI} sandbox lifts sequence effective
sample size by $\RSIESSRatio{}\times$, raises out-of-sample Daily Rank IC from
$\RSIGenZeroICMean{} \pm \RSIGenZeroICStd{}$ to $\mathbf{\RSIGenThreeICMean{} \pm \RSIGenThreeICStd{}}$,
and achieves a $\mathbf{\RSIGenThreeSharpeMean{} \pm \RSIGenThreeSharpeStd{}}$ annualized net Sharpe
($\text{DSR} = \RSIGenThreeDSRMean{}$, $\text{Max DD} = \RSIGenThreeMaxDDMean{}\%$) with Pareto
dominance across sparse small-cap and crisis slices.
\end{abstract}

\section{Introduction}
A financial research agent must decide which method suits a task, what data that method
requires, how to interpret its output, and when later evidence warrants revising its
decision. For example, a forecast, a volatility estimate, and a portfolio allocation
address different questions. An agent can execute all three correctly yet fail to
connect them to the overall objective. Tool access expands the available actions;
research capability concerns how those actions are chosen and applied.

This distinction becomes critical across repeated decisions and iterative self-improvement.
Useful domain conventions and parameter schemas can be severed by fixed-window RAG chunking,
while unconstrained verbal self-reflection (\texttt{Reflexion}) in non-stationary financial
markets is highly vulnerable to backtest overfitting and reward hacking: when an agent freely
modifies both its signal logic and evaluation scripts, it rapidly exploits look-ahead leaks,
concentrates weights into mega-cap outliers, or collapses effective sample size during event
bursts. Progressive skill routing, verified cross-episode associative memory, and physically
governed operator evolution address complementary dimensions of this challenge. Empirical
feedback must be cryptographically isolated from the agent's mutable workspace so that
synaptic and algorithmic updates reflect verified, defect-free out-of-sample evidence.

We investigate these questions through \textsc{fin-skills}, an open library linking
dated financial guidance with discoverable, executable quantitative methods, and
\textbf{Governed Financial Recursive Self-Improvement (\texttt{Fin-RSI})}. An agent
can inspect input requirements, select parameters, execute an algorithm, and evolve
feature-pooling and covariance-adaptation operators inside a strictly isolated sandbox.
We connect this interface with three core mechanisms: two-stage progressive skill routing
with strict point-in-time (\texttt{as\_of}) gating (\texttt{RAG-Jev}), a persistent
64-Kenyon-Cell mushroom-body associative memory gated by settlement-cleared portfolio returns,
and a SHA-256-locked \texttt{Fin-RSI} evolution loop driven by three physical diagnostic probes
(Pre-LayerNorm Scale-Cancellation, Intraday Burst Effective Sample Size $\operatorname{ESS}$,
and Subspace Signal-to-Noise Heterogeneity) under a three-way Pareto promotion gate.

Our autonomous-use and recursive evolution studies provide a clear empirical test: while
open-weight models successfully executed 43 quantitative algorithms across 64 portfolio
decisions, unguided tool execution and unconstrained verbal reflection failed to improve
net risk-adjusted returns over unassisted baselines. Without executable counterfactual guards,
point-in-time memory gating, and physical operator diagnostics, models frequently selected
unsuited algorithms, suffered severe drawdown degradation under regime shifts, or overfitted
sparse small-cap slices.

We examine four concrete questions in our empirical investigation: how autonomous tool
access alters the quantitative methods an agent selects and its resulting portfolio risk;
how atomic two-stage progressive skill routing with point-in-time gating compares against
fixed-window chunk RAG; whether verified cross-episode returns can guide subsequent
method selection under shifting market regimes; and how governed recursive operator
evolution (\texttt{Fin-RSI}) prevents reward hacking while improving macro, tail-slice,
and crisis-regime performance. In summary, this paper makes four primary contributions:
\begin{itemize}
\item \textbf{Standardized Quantitative Skill \& Guard Library (\textsc{fin-skills}):} We release
129 source-verified financial skills, 48 unified algorithm backends, and 37 executable
research guards (including \texttt{check\_panel\_balance} and \texttt{check\_trial\_ledger}) with
cryptographic AST-and-data receipt binding.
\item \textbf{Closed-Loop Routing \& Verified Associative Memory:} We formulate a two-timescale
architecture pairing point-in-time two-stage progressive skill routing (\texttt{RAG-Jev}) with
a 64-Kenyon-Cell mushroom-body associative memory gated exclusively by settlement-cleared,
guard-verified episode log-wealth returns.
\item \textbf{Governed Financial Recursive Self-Improvement (\texttt{Fin-RSI}):} We introduce a
physically grounded operator evolution framework that locks the read-only evaluation harness
via SHA-256 cryptographic hashes and evolves multimodal pooling, per-channel positive-part
James--Stein shrinkage \cite{james1961estimation}, and streaming rank-1 Sherman--Morrison--Woodbury
inverse-covariance adaptation \cite{sherman1950adjustment} coupled with Bernoulli Fisher
information gating under a three-way Pareto promotion criterion.
\item \textbf{Rigorous Multi-Seed Empirical \& 2D Panel Benchmarks:} Across $M=5$ independent
random seeds, 64 autonomous portfolio decisions, 21 cross-board market episodes, and a
\PanelBalancedRows{}-row company$\times$year balanced panel ($2018\text{--}2026$, constructed from
\CorpusTotalRecords{} multi-source records across \CorpusAnnounceTickers{} A-share and
\CorpusStockTwitsTickers{} US tickers), we isolate the causal contributions of counterfactual guard
repair, two-dimensional panel conditioning ($\Delta\text{Rank IC} = \PanelDeltaDailyIC{}$,
$\Delta\text{Sharpe} = \PanelDeltaSharpe{}$, $t = \PanelPairedTStat{}, p = \PanelPairedPVal{}$),
JEV System-One isotonic calibration ($\text{Sharpe} = \JEVSharpe{}$), associative plasticity, and
four-generation \texttt{Fin-RSI} evolution ($\text{Rank IC} = \RSIGenThreeICMean{} \pm \RSIGenThreeICStd{}$,
$\text{Sharpe} = \RSIGenThreeSharpeMean{} \pm \RSIGenThreeSharpeStd{}$, $\operatorname{ESS}$ ratio $\RSIESSRatio{}\times$).
\end{itemize}

\section{Related work}
\paragraph{Financial agent frameworks and benchmarks.}
Classical quantitative portfolio rules such as equal-weight diversification ($1/N$)
\cite{demiguel2009optimal}, time-series momentum (TSMOM) \cite{moskowitz2012time}, and
hierarchical risk parity (HRP) \cite{lopez2016building} provide transparent, leak-free
baselines but cannot synthesize unstructured disclosures or adapt across shifting tool
catalogs. Recent LLM agent frameworks augment language models with reasoning loops,
episodic memory, and multi-agent debate: ReAct \cite{yao2023react} and Reflexion
\cite{shinn2023reflexion} interleave tool execution with verbal self-critique; FinMem
\cite{yu2024finmem} introduces layered short-, mid-, and long-term FAISS episodic memory;
TradingAgents \cite{xiao2024tradingagents} orchestrates bull--bear analyst debates; and
FinAgent \cite{zhang2024finagent} combines multimodal market signals with tool reflection.
Meanwhile, InvestorBench \cite{kou2024investorbench}, StockBench \cite{chen2025stockbench},
and the Finance Agent Benchmark \cite{bigeard2025finance} evaluate sequential financial
decisions. However, existing frameworks rely on natural-language reflection or dense chunk
retrieval without executable counterfactual verification or locked evaluation harnesses,
leaving them vulnerable to silent look-ahead joins, unadjusted corporate actions, and
iterative backtest overfitting. Our study isolates the effects of tool access, point-in-time
progressive routing, counterfactual guards, associative memory, and governed recursive
operator evolution under identical market panels and transaction costs.

\paragraph{Verification guards, cross-episode plasticity, and governed self-improvement.}
Behavioral testing offers a structured view of model capabilities beyond aggregate
scores \cite{ribeiro2020checklist}. Financial backtest overfitting and selection bias
\cite{bailey2014deflated,bailey2017pbo}, alongside look-ahead leakage in financial agents
\cite{li2025profit}, motivate explicit checks on decision evidence. Our persistent memory
component adapts the fruit-fly mushroom-body model of \citet{huang2024memory} to update
sparse associative readouts exclusively from guard-verified, settlement-cleared financial
returns, while \texttt{Fin-RSI} complements empirical-Bayes shrinkage \cite{james1961estimation,ledoit2004honey}
and rank-1 matrix updates \cite{sherman1950adjustment} with cryptographic harness isolation
and multi-slice Pareto governance.

\section{Professional tools and domain knowledge}
\label{sec:library}
\textsc{fin-skills} exposes financial methods alongside the information an agent needs
to run them: task scopes, input requirements, dependencies, parameter conventions, and
dated source verifications. Domain skills route requests to relevant libraries; per-library
skills provide implementation guidance. The algorithm catalog covers portfolio
construction, forecasting, volatility estimation, technical signals, and execution
schedules, providing uniform programmatic contracts over quantitative methods.

\paragraph{Agent-selected execution.}
An agent can discover candidate algorithms, inspect their requirements, and execute them
with custom parameters. Structured outputs separate numerical results from missing
dependencies or runtime errors. An optional strategy adviser provides rule-based
suggestions without overriding model choices. In our evaluation, agents access 18
price-compatible algorithms, with requests and executions logged independently from
free-form text.

\paragraph{Information and model interfaces.}
Retrieval interfaces chunk packaged skills and documents, returning relevant passages
under strict as-of cutoffs to prevent look-ahead bias. Forecasting and prediction
adapters provide a unified fit--predict lifecycle, while portfolio optimizers expose
specialized execution interfaces. Appendix~\ref{app:library} details the complete
interface inventory, model lifecycle, and retrieval pipeline.

\section{Discussion: from execution to useful experience}
The empirical study shows that successful tool execution does not guarantee sound
investment decisions. Both Qwen models discovered and invoked algorithms without syntax
errors, yet neither outperformed unassisted baselines. The failure was not in execution,
but in method selection and risk management: 7B concentrated into single assets following
momentum signals, while 14B relied on mean reversion during trending phases.

These failure modes point directly to the roles of progressive skill routing, persistent
memory, and governed operator evolution. When retrieving from large quantitative repositories,
fixed-window chunking severs prose pitfall warnings from executable guard schemas ($25.0\% \pm 1.5\%$
fragmentation at top-5), whereas two-stage manifest routing preserves atomic skill specifications
at $4{,}039 \pm 42$ tokens ($-98.91\%$). Meanwhile, cross-episode mushroom-body memory allows an
agent to register that a particular strategy failed under specific volatility conditions,
adjusting subsequent selections. Furthermore, replacing unconstrained verbal self-reflection with
physically diagnosed \texttt{Fin-RSI} operator mutations eliminates pre-LayerNorm gradient
cancellation, restores sequence effective sample size during event bursts ($\RSIESSRatio{}\times$),
and suppresses small-cap estimation variance via per-channel James--Stein shrinkage and streaming
Woodbury covariance adaptation.

Finally, execution checks and cryptographic harness locks prevent the agent from reinforcing
spurious strategies. If an agent backtests on unadjusted prices, incorporates future data, or
mutates evaluation metrics during self-improvement, it observes artificial profits. Without
verification guards and a locked trial ledger, persistent memory and recursive evolution would
treat those illusions as positive reinforcement. Verification is therefore the necessary filter
that keeps both experiential learning and algorithmic self-improvement grounded in real market dynamics.

\section{Conclusion}
Access to financial algorithms gives language models the ability to compute, but not
the judgment to invest. In this paper, we structured tool use around progressive skill
routing, counterfactual execution checks, cross-episode associative memory updates, and
governed recursive operator evolution (\texttt{Fin-RSI}). Our experiments demonstrate that
while open-weight models readily discover and run specialized algorithms, turning tool
execution into effective decision-making requires atomic skill hydration, point-in-time
verification guards, feedback-driven synaptic plasticity, and Pareto-governed self-improvement.

\section*{Limitations}
This study has three primary operational scopes that bound its interpretation. First, our
backtest evaluations and autonomous portfolio decisions execute on daily currency reference
rates and end-of-day equity bars with parametric transaction-cost curves ($5\text{--}10\text{ bps}$)
rather than full Level-3 limit order books; live intraday institutional execution introduces
stochastic queue-priority decay, partial fills, and dynamic short-borrow fee spikes during
crowded liquidations. Second, while our open-weight Beacon audit matrix rigorously characterizes
3B--14B coding models across $M=5$ seeds, scaling multi-round counterfactual repair beyond
five dialogue turns can exhaust context budgets on smaller backbones unless paired with
automated AST patch localization. Third, while \texttt{check\_panel\_balance} effectively enforces
two-dimensional company$\times$year cell quotas ($q_{c,y} \le 36$) across \PanelBalancedRows{}
daily multi-source records, extending real-time stratified reservoir sampling to sub-second
global tick streams requires distributed state coordination across market ingestion partitions.

\section*{Ethics and Reproducibility}
All models, tools, and evaluation benchmarks adhere to open, reproducible protocols.
Software environments, execution digests, and audit traces are publicly available to
facilitate independent verification.
