\newcommand{\OverviewCaption}{%
What is in \lib{} and how an agent uses it. Left: one mark per item, in the real counts: the
\NSkills{} skills grouped by their \NPlugins{} plugins, the \NCards{} rule cards, the \NGuards{}
checks and the \NMethods{} self-improvement methods, over an engine of algorithms, data adapters,
a reference backtester and the benchmark. Middle: an agent is the user's own model plus the pieces
it picks, filled in the box (here the \texttt{fin-core} plugin, two rule cards, three checks and
\texttt{PlaybookLearning}), reached through MCP, tool schemas or the Python API. Right: on each task the agent writes a program and the checks run; a failed check goes
to the self-improvement method before the next run, within a budget that is the same for every
method, and a program that passes is delivered. Figure~\ref{fig:episode} follows one episode.}
