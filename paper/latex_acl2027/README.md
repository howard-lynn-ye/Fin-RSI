## Figure rules

Every figure is drawn at the size it is printed (ACL text width 16 cm, column 7.7 cm) and
included without scaling, so no version shrinks or enlarges it; no text is smaller than 7 pt.
TikZ figures use `\sffamily` (Helvetica under the times package) and matplotlib figures use TeX
Gyre Heros, its clone; code is in the body's typewriter face. Colours keep one meaning across
figures: skills and the library blue (`finblue`), checks orange (`finorange`), self-improvement
aqua (`finaqua`), pass and fail green and red with a check or cross. The data figures share
`STYLE` in `make_figures.py`.

## Numbers come from the code

`numbers.tex`, `cards_table.tex` and `tasks_table.tex` are generated. Do not edit them:

```bash
python paper/latex_acl2027/make_numbers.py   # from the repository root
```

`make_figures.py` draws the data figures the same way: Figure 1 (a) and the real-panel figure
from the real panel (set `FIN_TASKS_REAL_PANEL`; the prices stay out of the repository), and the
`execution_lag` figure from the seed-11 panel and the library's own `positions()`, perturbing
prices exactly as the guard does. `figures/episode_src/check.py` re-runs the two programs of
Figure 1 (b) through the judge on every seed and the real panel.

`make_results.py` draws the result figures from the episode records that `rsi.benchmark()`
writes (`python paper/latex_acl2027/make_results.py runs/rsi-bench/*/episodes.jsonl`). Until the
runs exist, `--placeholder` draws them from null generated records, stamped PLACEHOLDER; such
figures must not reach a submission, so the FinFM versions do not include them.

`make_numbers.py` reads the catalog, the guard registry, the tool exporter, the rule cards, the task suite
and the RSI defaults, and it recomputes the reference-versus-library agreement on every task
and seed. Rerun both after any change to those, then rebuild.

```bash
cd paper/latex_acl2027
latexmk -pdf main.tex
```

`\pending{...}` marks text that waits for the experiments; it prints in red and must be gone
before submission.
