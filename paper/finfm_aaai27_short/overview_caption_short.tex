\renewcommand{\OverviewCaption}{%
What is in \lib{} and how an agent uses it. Left: the library as a cabinet whose tray holds one
piece per item, in the real counts (a book per skill, grouped by plugin; the rule cards; a cube
per check; a token per self-improvement method), with the engine on its front. Middle: an agent
is the user's own model plus the pieces it picks, or that \texttt{route()} names from the task
text; it is reached through MCP, tool schemas or the Python API. Right: on each task the agent
writes a program and the checks run; a failed check goes to the self-improvement method before
the next run, within one budget for every method. A program that passes is delivered, and only
then does a hidden grader compare it with the task's reference. Figure~\ref{fig:episode}
follows one episode.}
